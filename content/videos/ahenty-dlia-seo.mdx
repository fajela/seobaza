## Стартовий набір SEO-агента

Подарунок зі стріму: [завантажити архів](/files/seobaza-agent-starter.zip). Усередині шаблон інструкцій AGENTS.md і три скіли для SEO:

- **seo-title-description**: title і meta description з аудитом ключів, перевіркою довжини й унікальності
- **fact-check-sources**: перевірка фактів за першоджерелами і таблицею статусів: перевірено, не перевірено, не так
- **gsc-weekly-report**: звіт про зміни в Search Console з вашого експорту CSV, без API і програмування

Скіли зроблені за відкритим стандартом Agent Skills, тож працюють у Claude, Claude Code, Codex, Cursor та Antigravity. Як встановити, написано в README всередині архіву. У Claude кожен скіл завантажується окремим ZIP через Customize, Skills, і потрібно ввімкнути виконання коду в налаштуваннях.
