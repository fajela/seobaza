# Як додати свою статтю на SEO BAZA

Ласкаво просимо до української SEO-спільноти! Ми раді, що ви хочете поділитися своїми знаннями. Ось як це зробити:

## Крок 1: Fork репозиторію

1. Перейдіть на [GitHub сторінку проекту SEO BAZA](https://github.com/fajela/seobaza)
2. Натисніть кнопку **Fork** у правому верхньому куті
3. Це створить копію репозиторію у вашому акаунті

## Крок 2: Створіть нову гілку

```bash
git checkout -b article/your-article-name
```

Використовуйте описову назву для вашої гілки, наприклад:
- `article/technical-seo-checklist`
- `article/core-web-vitals-guide`

## Крок 3: Напишіть свою статтю

Створіть новий файл в директорії `content/articles/` з розширенням `.mdx`:

```markdown
---
title: "Назва вашої статті"
description: "Короткий опис (2-3 речення)"
author: "Ваше ім'я"
date: "2025-12-27"
tags: ["SEO", "Technical SEO", "Інші теги"]
---

# Заголовок статті

Ваш контент тут...
```

### Підтримувані можливості

- ✅ **Markdown** - заголовки, списки, посилання
- ✅ **Код блоки** з підсвічуванням синтаксису
- ✅ **Таблиці** та GitHub Flavored Markdown
- ✅ **Зображення** та медіа контент
- ✅ **React компоненти** (опціонально)

### Як додавати зображення

**Варіант 1: Зображення з інтернету (найпростіше)**

Використовуйте звичайний Markdown синтаксис:

```markdown
![Alt текст](https://example.com/image.jpg)
```

**Варіант 2: Локальні зображення**

1. Покладіть зображення в папку `public/images/` у вашому fork
2. Використовуйте відносний шлях:

```markdown
![Alt текст](/images/your-image.jpg)
```

**Варіант 3: Зображення з підписом**

```markdown
![Скріншот Google Search Console](/images/gsc-screenshot.jpg)
*Приклад звіту в Google Search Console*
```

**Рекомендації:**
- Оптимізуйте зображення перед завантаженням (до 500KB)
- Використовуйте описові alt теги для SEO
- Формати: JPG для фото, PNG для скріншотів, WebP для кращої оптимізації

## Крок 4: Commit та Push

```bash
git add .
git commit -m "Add: Your Article Title"
git push origin article/your-article-name
```

## Крок 5: Створіть Pull Request

1. Перейдіть на вашу сторінку fork на GitHub
2. Натисніть **Compare & pull request**
3. Опишіть вашу статтю
4. Натисніть **Create pull request**

## Рекомендації щодо написання

### Структура статті

1. **Вступ** - чому це важливо
2. **Основний зміст** - покрокові інструкції або пояснення
3. **Висновки** - що ми дізналися
4. **Додаткові ресурси** - корисні посилання

### Стиль написання

- Пишіть простою українською мовою
- Використовуйте приклади та скріншоти
- Додавайте code snippets де доречно
- Структуруйте текст заголовками
