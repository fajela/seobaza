Microsoft [запустили пошук для AI-агентів Web IQ](https://blogs.bing.com/webiq/2026/11/web-iq-is-now-broadly-available-build-better-agents-that-keep-up-with-the-world/). Тепер ним може користуватися будь-який клієнт хмари Microsoft Azure. Web IQ — це пошук Bing, перероблений для AI-агентів. Агент надсилає запит через API і отримує уривки зі сторінок, на які спирає свою відповідь. Анонс зробили на конференції Microsoft Ignite, у блозі його написав Jordi Ribas, президент Microsoft з пошуку і AI. У дописі в X він пише, що на Web IQ працюють ChatGPT, Copilot і Mistral.

Про [перший запуск Web IQ на Microsoft Build у червні](/news/2026/06/microsoft-zapustyv-web-iq-poshukivnyk-dlia-ai-ahentiv-1651) ми писали окремо.

## Що нового у Web IQ

- Web IQ Auto став режимом за замовчуванням. За один запит він сам шукає у вебі, картинках, відео, новинах, погоді й місцях і повертає тільки потрібні уривки замість цілих сторінок.
- Auto Advanced для складних запитань перевіряє, чи вистачає знайденого, переформульовує запит і шукає ще. Jordi Ribas пише, що обидва режими розбивають запитання на кілька підзапитів. Це розгалуження запиту, query fan-out, [так тепер працює і пошук Google на Gemini 4 Hydrogen](/news/2026/11/google-perevely-poshuk-na-gemini-4-hydrogen).
- Scopes дозволяє компанії обмежити пошук свого агента списком дозволених сайтів або виключити окремі джерела. Jordi Ribas називає це власним налаштованим пошуком для агентів.
- Нові типи даних: погода з прогнозних моделей Microsoft, структуровані дані про понад **207 млн** компаній і місць по всьому світу, а в закритому тесті понад **40 млрд** товарних пропозицій з картинками, описами й характеристиками.
- Компанія може підключити тексти, на які вже купила ліцензію, і Web IQ видає їх разом з результатами з вебу в одному відсортованому списку.
- Медичні запитання Web IQ розпізнає сам і ставить вище клінічно релевантні надійні джерела. Надійність оцінюють за принципами Національної академії медицини США.
- Для клієнтів з регульованих галузей є режим, у якому запити не зберігаються.

Ціни Microsoft знизили. Тисяча звичайних запитів у Web IQ коштує **$7**, в режимі Auto **$8**, в Auto Advanced **$9**, розповів Jordi Ribas в [інтерв'ю The New Stack](https://thenewstack.io/microsoft-web-iq-agents/). Стартова ціна **$1** за тисячу стосується Browse, коли адреса сторінки вже відома.

## Бенчмарки Web IQ проти Perplexity, Exa і Parallel

Усі порівняння провели самі Microsoft.

- Свіжість джерел перевіряли бенчмарком FreshSearch, який Microsoft виклали у відкритий доступ. Він оцінює, як швидко сервіс знаходить щойно опубліковані сторінки і наскільки свіжі джерела дає на запити, де важлива дата. Web IQ Auto набрав **87,5** зі 100, Parallel 82,4, звичайний режим Web IQ 81,2, Exa 3.0 Auto 73,5, Perplexity 57,9.
- За швидкістю Web IQ обігнав Perplexity, Exa, Brave, You.com, Parallel і Tavily. Порівнювали час, у який вкладаються 95% відповідей, 8 листопада у 8 регіонах, по 1000 запитів на регіон. Мілісекунди є тільки на графіку в блозі.
- На 500 запитах про категорії товарів Web IQ знайшов на **57%** більше товарів, які відповідали всім умовам запиту, ніж найближчий конкурент.
- Клієнт Microsoft Genspark каже, що час відповіді їхнього голосового асистента з Web IQ скоротився з **6** секунд до **0,6**.

## Як сайт потрапляє у Web IQ

Web IQ шукає по власному індексу Microsoft, і кожен результат містить посилання на сторінку-джерело. Індекс збирає Bingbot, той самий бот, що працює для пошуку Bing і Copilot. Сторінки, закриті в robots.txt, Bingbot не обходить, тож у Web IQ їх немає. Сторінки з noindex не потрапляють в індекс пошуку. Окремо заборонити брати сторінку джерелом для відповідей AI можна мета-тегом, [який Bing анонсували 30 жовтня](/news/2026/10/piatnychni-novyny-30-zhovtnia-2026), враховувати його почнуть з 1 лютого 2027.
