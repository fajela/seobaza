# Матеріали випуску за 25 липня 2026

Робочі файли до [п'ятничних новин за 25 липня](/news/2026/07/piatnychni-novyny-25-lypnia-2026).

- `tg-post.txt` — допис у Telegram, звичайний текст
- `tg-post.html` — той самий допис зі вшитими посиланнями, відкрити в браузері й скопіювати
- `soc-versions.html` — версії для Facebook, LinkedIn, Threads та Instagram з лічильниками символів і кнопками копіювання
- `article-preview.html` — сторінка випуску на вичитку, картинки вбудовані в файл

Приватні матеріали сесії (транскрипт, інбокс) сюди не входять, вони в окремому приватному сховищі.
