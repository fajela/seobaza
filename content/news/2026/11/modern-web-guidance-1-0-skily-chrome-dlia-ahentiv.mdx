Modern Web Guidance 1.0, стабільна версія набору скілів для агентів для коду, вийшла 10 листопада. Chrome [оголосили про реліз у блозі для розробників](https://developer.chrome.com/blog/modern-web-guidance-v1). Скіли дають агенту на кшталт Claude Code, Codex чи Cursor знання про сучасні можливості браузерів, кращі практики швидкості, доступності й безпеки і дані про сумісність з браузерами. Ранню версію показали на Google I/O в травні, ми згадували її в [п'ятничних новинах 16 жовтня](/news/2026/10/piatnychni-novyny-16-zhovtnia-2026). З версією 1.0 до проєкту приєдналися Firefox і Edge.

Скіли потрібні тим, хто робить сайти з AI-агентами: без них агент часто пише робочий, але застарілий код. Вищих позицій у пошуку чи появи у відповідях AI Chrome в анонсі не обіцяють. Частина гайдів стосується швидкості завантаження, зсувів макета й реакції сторінки на кліки, тобто показників Core Web Vitals.

## Що нового в Modern Web Guidance 1.0

- Сканування наявного коду. Агент аналізує HTML, CSS, JavaScript і package.json, знаходить застарілі обхідні рішення, зайві залежності й поліфіли, тобто код, який додавав старим браузерам підтримку нових функцій, і проводить оновлення. Запускається командою `/modern-web-guidance Modernize the code in this directory`. У першому релізі сканування шукає обмежений набір відомих шаблонів.
- Більше гайдів. За словами Chrome, база закриває сотні перевірених прогалин у знаннях моделей.
- Перевірка людьми. Кожен гайд затверджує технічний лід свого напряму. Гайди про інтерфейс окремо тестували фахівці з доступності, які самі щодня користуються допоміжними технологіями.
- Публічні тести. На [панелі з результатами](https://goo.gle/mwg-evals) видно, наскільки краще агент пише код зі скілами, ніж без них.

## Що Modern Web Guidance знайшли на сайті SEO Baza

Ми поставили скіли на код seobaza.com.ua 14 листопада. Інсталятор додав у проєкт теку .agents/skills з каталогом на 208 гайдів і підключив її до Claude Code. Наприкінці встановлення він попереджає, що Google збирають анонімну статистику використання. Вимикає її змінна середовища DISABLE_TELEMETRY=1.

Сканування застарілого коду пройшло без жодного збігу за 35 правилами. Сканер сам пише, що ці правила покривають близько 20% бази гайдів. Сайт працює на Next.js, у новому форматі його запущено в травні 2026 року.

![Термінал з командами встановлення Modern Web Guidance і скануванням коду сайту SEO Baza: нуль збігів у 33 гайдах](/images/news/2026/11/modern-web-guidance-skanuvannia-saitu-seo-baza-featured.jpg)

Далі агент звірив перемикач темної теми з гайдом dark-mode-toggle і знайшов три розбіжності:

- Перемикач має два стани, світлий і темний. Після першого кліку сайт більше не повертається до системної теми. Гайд вимагає, щоб людина могла повернути системне налаштування.
- Темну тему вмикає клас, який додає JavaScript. Якщо скрипти вимкнено, людина з темною системною темою бачить світлий сайт.
- Кнопка підписана для програм читання екрана англійською, Toggle theme, і не каже, яку тему ввімкне.

Усі три пункти агент виправив за тим самим гайдом. Перемикач тепер зберігає вибір, тільки коли він відрізняється від системної теми. Без JavaScript сайт іде за системним налаштуванням. Кнопка підписана українською і називає тему, яку ввімкне.

У тому ж гайді написано, що більшості сайтів постійний перемикач теми в шапці не потрібен і досить іти за системним налаштуванням.

## Де агенти для коду помиляються без скілів

Найновіші моделі зазвичай видають робочий код. За тестами Chrome, слабких місць у них чотири:

- Доступність: керування фокусом з клавіатури, підтримка налаштування зменшеного руху, зрозуміла для допоміжних технологій перевірка форм.
- Зручність: свайпи й жести, анімації діалогів і спливних вікон, світла й темна теми.
- Швидкість: розбивання довгих задач у головному потоці браузера, запобігання зсувам макета.
- Безпека: безпечне очищення HTML, сувора Content Security Policy, вхід за ключами доступу passkeys.

Моделі також часто роблять на JavaScript те, що HTML і CSS уміють самі з меншим кодом. Скіли підказують агенту вбудовану функцію браузера й зважають на те, які браузери має підтримувати проєкт. Для цього в гайди вшиті дані [Baseline](https://web.dev/baseline) про підтримку вебфункцій у браузерах.

## Перевірка швидкості через Chrome DevTools for agents

Chrome радять ставити скіли разом з [Chrome DevTools for agents](https://developer.chrome.com/docs/devtools/agents). Через цей інструмент агент запускає сторінку в браузері й бачить, як вона працює. Приклад з анонсу: агент записує трасування швидкості на імітованому слабкому процесорі й переробляє код, доки жодна задача не блокує головний потік довше 50 мілісекунд. Довші задачі погіршують INP, показник Core Web Vitals про швидкість реакції сторінки на дії користувача.

## Результати компаній зі скілами Chrome

В анонсі є цифри чотирьох компаній, усі з їхніх власних звітів:

- Pensionbazaar, індійська платформа пенсійного планування, робить нові сторінки за кілька годин замість чотирьох днів. Помилок інтерфейсу на нових екранах стало менше на понад 90%.
- WeTV, відеосервіс Tencent, додали агента в автоматичне збирання й викладання коду. Агент сам знаходить причину й виправляє 90% провалених перевірок швидкості.
- note inc., японська платформа для авторів з понад 90 млн активних користувачів на місяць, провели 180 тестових прогонів на власному коді. Частка пройдених перевірок на сучасні вебпрактики виросла з 61% до 94%.
- MetaMask, криптогаманець, запустили бота зі скілами на перевірку кожної зміни коду у своєму браузерному розширенні. За п'ять тижнів бот переглянув близько 480 змін, прокоментував 64, інженери виправили 43 зауваження.

## Як встановити Modern Web Guidance

Скіли ставляться командою з теки проєкту:

```
npx modern-web-guidance@latest install
```

Попередню версію оновлює команда `npx modern-web-guidance@latest update`. Ще скіли є в маркетплейсах плагінів Claude Code, Codex, Cursor, Antigravity, Copilot, WebStorm, Kimi Code і Grok Build. Деталі в [документації Modern Web Guidance](https://developer.chrome.com/docs/modern-web-guidance) і в [репозиторії на GitHub](https://github.com/GoogleChrome/modern-web-guidance).
