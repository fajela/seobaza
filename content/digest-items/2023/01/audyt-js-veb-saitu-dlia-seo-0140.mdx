Якщо взяти за основу [цю статтю by Sarah Taher](https://www.sara-taher.com/javascript-audit-for-seo/), то коротко ваш **чекліст** виглядатиме так:

1. **Відключить JavaScript** в Chrome через DevTools і перевірте шаблонні і основні сторінки: **видно весь основний контент, зображення включно?** 
_Правильна відповідь — так._

2. **Для loading lazy використовується src-data або src?**
_Правильна відповідь — src._

3. Чи використовує сайт **безкінечну прокрутку без відображення змін в URL-адресі?**
_Правильна відповідь — URL має змінюватись з безкінечною прокруткою._

4. Чи створює фреймворк **фрагментовані URL?** Ті, що з #.
_Правильна відповідь — URL з # не мають завантажувати новий контент, який без них не видно на сторінці._

5. **Чи блокуються файли js, які потрібні для рендерингу, в robots.txt?**
_Правильна відповідь — ні._

6. **Редиректи через JavaScript?**
_Правильна відповідь — ні._
