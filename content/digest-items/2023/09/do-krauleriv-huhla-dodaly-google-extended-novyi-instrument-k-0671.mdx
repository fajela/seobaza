До краулерів гугла додали Google-Extended — новий інструмент контролю для веб-сайтів, який дозволяє вирішувати, чи можуть їхні сторінки використовуватися для вдосконалення моделей штучного інтелекту Bard та Vertex AI, включно з майбутніми поколіннями цих моделей.

За допомогою Google-Extended веб-адміністратори отримують можливість обмежити доступ до контенту сайту для AI-моделей Google. 

Google-Extended - це окремий продукт, який не має власного HTTP user agent, а використовує наявні user agent Google. Контроль здійснюється за допомогою спеціального токена в файлі robots.txt.
