- Bing стане пошуковою системою ChatGPT за замовчуванням

- Microsoft планує інтегрувати такий самий відкритий стандарт плагінів, як ChatGPT

- Розробники тепер зможуть інтегрувати свої додатки в Microsoft 365 Copilot

- 50+ плагінів в Microsoft 365 Copilot стануть доступними, включно Atlassian, Adobe, ServiceNow, Thomson Reuters, Moveworks і Mural

- Обіцяють полегшити життя за допомогою нової Azure AI Studio, яка дозволить легше інтегрувати зовнішні джерела даних. В Azure Machine Learning додають нові інструменти

- Нова платформа для аналітики — [Microsoft Fabric](https://azure.microsoft.com/en-us/blog/introducing-microsoft-fabric-data-analytics-for-the-era-of-ai/). За допомогою інтегрованого Copilot, кожен бажаючий зможе нібито легко взаємодіяти з платформою і отримувати відподі з необхідними даними

- В червні в Windows 11 інтегрують Copilot.
